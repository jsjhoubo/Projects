## Overview

This homework covers writing SQL queries against a relational database. It tests knowledge of:

- Basic `SELECT`, `FROM`, `WHERE` clauses
- Aggregation functions (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`)
- `GROUP BY` and `HAVING`
- Joins (`INNER JOIN`, `LEFT JOIN`, etc.)
- Subqueries and correlated subqueries
- Window functions
- Common Table Expressions (CTEs)
