## Overview

This homework covers distributed database systems, including:

- Distributed query processing and data partitioning (horizontal, vertical, hash, range)
- Distributed transactions and Two-Phase Commit (2PC)
- Consistency models (eventual, linearizability, serializability)
- Replication strategies (primary-backup, multi-leader)
- CAP theorem and PACELC model
- Distributed concurrency control (MVCC at scale, Google Spanner)
- Fault tolerance and recovery in distributed settings
